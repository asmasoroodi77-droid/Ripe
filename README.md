## What is in this folder

The Ripe prototype in plain HTML, CSS and JavaScript. No libraries, nothing to install. The design is `../prototype/ripe-app.html`.

**Start:** double-click `index.html`. **Review bar:** add `?review=1` to the address.

| Path | What it holds |
|---|---|
| `screens/` | One folder per screen, each with its own code and CSS file |
| `data/exampleData.js` | All example data |
| `shared/` | Colours and type, the bottom bar, saved data, timer, messages |
| `main.js` | How the screens hand over to each other |
| `StateSwitcher.js` | The review bar |
